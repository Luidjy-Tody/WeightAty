# Backend (à développer en équipe)

Aucun serveur ni API n’est implémenté pour le moment. Définir la technologie backend en équipe avant le développement.

La base locale officielle est `weightaty_db`. Ne jamais committer de mots de passe, jetons ni fichiers `.env` réels.

Voir `../frontend/docs/API.md` pour les besoins fonctionnels et `../database/README.md` pour installer MySQL.
